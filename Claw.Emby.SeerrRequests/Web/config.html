add_to_queue Seerr Requests

Adds Request this now to the item menu on trailers and on movies or shows that are not already in this library. Status is checked in Seerr first. Requests are sent as the matched Seerr user; quotas and approvals stay in Seerr.

Seerr Requests is switched off: the menu entry is hidden and new requests are refused. Activity and settings are kept. Switch it on in the General tab.

Seerr

The key is stored on the server, never shown in full, and never written to the Emby log. Leave this box as-is to keep the current key. Quotas and approvals stay in Seerr.

Who can see "Request this now"

Checked users see the menu. Unmatched users still get a clear message and are never sent as the Seerr admin.
Off = only the libraries and channels you tick below.

User mapping

Seerr users are matched automatically by the Emby/Jellyfin user id stored in Seerr. A manual override here always wins. There is no admin fallback.

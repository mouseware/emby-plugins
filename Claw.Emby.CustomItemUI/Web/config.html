Custom Item UI

Web client only. Moves Links up, wraps media paths for VLC, styles external links, and can rearrange the admin Dashboard. Re-injects on Emby startup after updates.

Links section

VLC path links

External link buttons

Any CSS color (#ffffff, white, rgb(...)). Leave blank to use Emby's default.
Plain declarations are applied to the link buttons, for example background:#333; padding:.4em 1em;. Full rules with selectors are used as written, for example .itemLinks a:hover { background:#52b54b; }.

Who it applies to

Item-page tweaks only. The dashboard layout applies to every admin (the Dashboard is admin-only).

Dashboard layout

Rearranges the admin Dashboard home page (Server info, Alerts, Now playing, Activity, ...). Each row is 12 columns wide. Sections Emby only shows when needed (Running tasks, Active recordings, Maintenance, Now playing while nothing plays) take no space, and with "grow to fill" their row-mates expand. If Emby's dashboard markup changes and a section can't be found, the dashboard is left untouched.

Off = Emby's stock dashboard, exactly as Emby renders it.
Drag a section by its ⋮⋮ handle into another row, between sections, or onto "new row". The arrow buttons do the same from the keyboard. Width is in twelfths of the row.
SectionVisibleRowOrder in rowWidth (of 12)
Rows and orders are renumbered (1, 2, 3...) when you leave a field. A row's widths must add up to 12 or less.
Example: Now playing (8) + Running tasks (4) → Now playing is full width while no task runs.
Icon, user, action, item (click to open), device, date. Click a column header to sort. Same entries and refresh as Emby's list.
Icon, event (with details underneath when Emby has them), date.

General

Off = no item-page or dashboard changes. The script stays injected but does nothing.

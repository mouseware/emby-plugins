What is checked

Scanned in addition to the library folders. All file types are hashed.
Skip = never hashed or listed; files already tracked are removed from tracking with their history (files on disk are never touched). Auto-accept (below) = still hashed, but a rewrite is accepted silently instead of being reported.
Emby and other tools rewrite metadata files (.nfo, artwork). A new hash with a changed size or time is accepted for these.

Full scan

0 = never skip. Start scan here always runs.
Schedule: Dashboard → Scheduled tasks → Media Integrity → Full integrity scan (checks weekly; a full scan runs when the last full verification is older than the days below, default 182 = about 6 months). Scans run at low priority, one file at a time, and resume where they stopped.

Notifications

Choose where they go under Settings → Notifications (category Media Integrity).

Old hash database

Imported once on first start from a read-only copy; the original is never changed.

General

Off = the running full scan stops (it resumes from that file later), manual checks are cancelled, nothing new is hashed, the file list is not refreshed and Verify integrity disappears from the item menu. Stored hashes, history and settings are kept; files of new items queued while off are hashed when you switch it on again.

About

Version–
Scriptclaw-media-integrity.js, injected into the web client's index.html at Emby startup (re-applied after Emby updates). It adds Verify integrity to the item menu; while the plugin is off it stays injected but adds nothing.
